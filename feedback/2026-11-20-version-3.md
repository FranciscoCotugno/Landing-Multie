## 2. Scroll con inercia (prioridad alta)

- **Hoy:** el scroll es el del navegador. Cada giro de la ruedita se mueve unos 0,2 s y frena en seco. Lenis no está corriendo, o no está conectado.
- **Tiene que pasar:** Lenis con estos valores exactos, conectado a GSAP y ScrollTrigger:

```js
import Lenis from 'lenis'
import gsap from 'gsap'
import { ScrollTrigger } from 'gsap/ScrollTrigger'
gsap.registerPlugin(ScrollTrigger)

const lenis = new Lenis({ lerp: 0.09, smoothWheel: true })
lenis.on('scroll', ScrollTrigger.update)
gsap.ticker.add((time) => lenis.raf(time * 1000))
gsap.ticker.lagSmoothing(0)
```

- Una sola instancia de Lenis para toda la página, creada una vez (si usás React, en un componente de layout, con su `destroy()` al desmontar).
- En celular se deja el scroll táctil nativo (es lo que Lenis hace por defecto: no actives `syncTouch`).
- Si el usuario pidió reducir el movimiento (`prefers-reduced-motion: reduce`), no se crea Lenis.
- Los botones que llevan a una sección (por ejemplo "Contacto") usan `lenis.scrollTo(...)`, no `scrollIntoView`.
- **Se comprueba:**
  - En la consola, `document.documentElement.classList.contains('lenis')` da `true`.
  - Con la ruedita, un giro sigue deslizando y frena de a poco durante casi un segundo. Varios giros seguidos se encadenan sin cortes.
  - Se siente igual que los bocetos, que ya tienen Lenis con `lerp: 0.09`.
