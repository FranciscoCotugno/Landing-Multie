# Multie — landing

Landing de Multie, un producto de Funke. Este repo arranca con todo lo necesario para construirla: la biblia, las referencias, los diseños y los assets. El código se suma acá mismo.

**Empezá por [BIBLIA.md](BIBLIA.md).** Ahí está qué es, qué dice, cómo se mueve, cómo se ve y cómo trabajamos.

## Qué hay en el repo

| Carpeta | Qué tiene |
| --- | --- |
| `BIBLIA.md` | La biblia completa: contexto, guion, escenas, dirección visual, assets, requisitos técnicos y forma de trabajo. |
| `CLAUDE.md` | Reglas del proyecto para Claude Code. Las lee solo al abrir el repo. |
| `referencias/` | Paleta, Nebula, la grabación del efecto del footer y el manual de marca de Funke. |
| `diseno/` | `direccion-A.html` (cómo se ve), `prototipo.html` (cómo se mueve) y capturas. Se abren con doble clic en el navegador. |
| `assets/logo/` | Logo de Multie en blanco, negro, naranja y gris, la versión editable y la fuente del logo. |
| `assets/fuentes/` | Geist y Geist Mono (provisorias, licencia libre) y las fuentes de Funke: Owners XNarrow y Neue Haas Display. |
| `assets/provisorios/` | Videos cortos de prueba, embudo, tira de video y teléfonos. Se reemplazan por los finales. |
| `.github/CODEOWNERS` | Los archivos de diseño, textos y assets necesitan la aprobación de Cotu. |

## Antes de publicar

- Las fuentes de Funke y la del logo (Getai) son para uso interno. Antes de ponerlas en la web hay que confirmar la licencia web.
- Mail y WhatsApp reales, y dominio.
